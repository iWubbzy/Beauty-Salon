Wubbzy's Beauty Salon - HTML5 version
=====================================

Quick start: double-click index.html (works in Chrome, Edge, Firefox, Safari).

Best sound: serve this folder over HTTP, then open http://localhost:8000
    python3 -m http.server 8000

Tap "Tap to Play" first (browsers only allow sound after a tap).
Mouse and touch both work. Settings are saved in the browser.
The menu's Parents button asks for a year of birth (14+) and leads to the
For Parents page and Help screen, whose buttons open Cupcake Digital's web pages.
